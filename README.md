# PF_Project-Rock-Paper-Scissor
A CLI-based Rock Paper Scissors game developed in C.
# Features
- Player vs Computer
- Random computer choices
- Score tracking
- Best of 3 rounds
- Random computer choice
- Play again option
- Draw Detection

## Technologies
- C Programming
- Command Line Interface
