# PF_Project-Rock-Paper-Scissor
A CLI-based Rock Paper Scissors game developed in C.
# Features
# Features
* Player vs Computer gameplay
* Random computer choices
* Rock, Paper, Scissors game rules
* Best-of-three match system
* Round-by-round winner detection
* Draw detection
* Player score tracking
* Computer score tracking
* Live score display after each round
* Player choice display
* Computer choice display
* Input validation for player choices
* Invalid input handling
* Match winner announcement
* Play again option
* Exit option after completing a match
* Validation for Play Again / Exit options
* Multiple matches without restarting the program
* Clear game start and match result messages
* User-friendly command-line interface
* Welcome screen with game instructions
* Final "Thanks for playing" message
